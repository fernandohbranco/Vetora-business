# Sprint 04 — Kit VETORA Conteúdo
**Status:** Aguarda Sprint 03 | **Depende de:** Funil low ticket validado  
**Objetivo:** Construir os 8 módulos completos do Kit VETORA na Cakto — conteúdo rico, copy de percepção de valor, design profissional alinhado ao branding.

---

## Produto a construir

**Nome:** Kit VETORA Completo  
**Posição no funil:** Upsell principal (pós-compra do Diagnóstico de Autoridade)  
**Preço:** R$397  
**Plataforma:** Cakto (área de membros)  
**Anchor:** R$897 (Kit + 1h consultoria)

---

## Princípios de construção

- Conteúdo rico, prático e objetivo — não genérico
- Copy interno em cada módulo reforça valor e comprometimento do usuário
- Exemplos baseados nos cases reais: Autec, Rancho 517, FRBranco
- Cada módulo tem critérios objetivos de saída — o usuário sabe quando terminou
- Visual clean e profissional (não parece PDF genérico de Canva)
- Tom VETORA: consultivo, direto, técnico, sem buzzwords

---

## Tarefas por módulo

### Módulo 01 — Diagnóstico de Marca
**O que entrega:** Checklist de 30 pontos (expandido do produto low ticket) + questionário diagnóstico completo + mapa de gaps priorizados  
**Diferença do low ticket:** O low ticket identifica. O Módulo 01 aprofunda e cria o mapa de trabalho para os módulos seguintes.

- [ ] Estrutura e escopo detalhado
- [ ] Conteúdo completo (checklist + questionário + interpretação)
- [ ] Exemplos preenchidos com base nos cases reais
- [ ] Design e template aplicado

### Módulo 02 — Posicionamento e Estratégia
**O que entrega:** Tese de posicionamento + definição de categoria + proposta de valor + arquétipo de marca

- [ ] Framework de posicionamento (4 perguntas que definem a tese)
- [ ] Exercício de definição de categoria (onde você compete)
- [ ] Template de proposta de valor preenchível
- [ ] Mapa de arquétipos com guia de escolha
- [ ] Exemplo aplicado (Autec ou Rancho 517)
- [ ] Critério de saída: tese de posicionamento escrita e validada

### Módulo 03 — Identidade Verbal
**O que entrega:** Tom de voz definido + banco de 30 frases calibradas + guia de o que dizer e o que evitar

- [ ] Framework de tom de voz (4 dimensões)
- [ ] Exercício de calibração com exemplos comparativos
- [ ] Banco de 30 frases (10 para LinkedIn, 10 para apresentações, 10 para site)
- [ ] Lista de frases proibidas (para o perfil do ICP)
- [ ] Critério de saída: tom de voz definido em 1 parágrafo

### Módulo 04 — Identidade Visual
**O que entrega:** Diretrizes de paleta, tipografia, checklist de logo, guia de aplicação básica

- [ ] Framework de briefing visual (não exige designer)
- [ ] Guia de paleta: como escolher e justificar cores
- [ ] Guia de tipografia: critérios de escolha por perfil de marca
- [ ] Checklist de avaliação de logo (30 critérios)
- [ ] Critério de saída: briefing visual completo + checklist de logo preenchido

### Módulo 05 — Estrutura de Site
**O que entrega:** Blueprint completo do site por seção + copy de cada seção + checklist UX/UI

- [ ] Mapa de seções (quais existir e em qual ordem)
- [ ] Copy modelo para cada seção (adaptável)
- [ ] Critérios de UX/UI para cada seção
- [ ] Checklist de lançamento (baseado no checklist do kit-vetora)
- [ ] Exemplos visuais de wireframe anotado
- [ ] Critério de saída: brief completo para construção ou revisão do site

### Módulo 06 — Apresentação Comercial
**O que entrega:** Estrutura de narrativa executiva + 15 slides templates + guia de adaptação

- [ ] Framework narrativo (problema → solução → prova → oferta)
- [ ] Template de 15 slides adaptável
- [ ] Guia de copy para cada slide
- [ ] Checklist de apresentação antes de enviar
- [ ] Critério de saída: apresentação revisada e pronta

### Módulo 07 — Biblioteca de Prompts de IA
**O que entrega:** 40 prompts calibrados por categoria

Categorias:
- Copy (bio, pitch, proposta, e-mail de follow-up)
- Visual (briefing para designer, descrição de logo, brief de identidade)
- Estratégia (análise de posicionamento, revisão de copy, mapeamento de concorrência)
- Revisão (auditoria de site, checklist de apresentação, diagnóstico de marca)

- [ ] 40 prompts escritos e testados
- [ ] Guia de uso de cada categoria
- [ ] Exemplos de output esperado

### Módulo 08 — Guia de Implementação
**O que entrega:** Roteiro de 4 semanas com prioridades + checklist final de conclusão

- [ ] Semana 1: diagnóstico + posicionamento
- [ ] Semana 2: identidade verbal + visual
- [ ] Semana 3: site + apresentação
- [ ] Semana 4: revisão final + lançamento
- [ ] Checklist de conclusão do Kit
- [ ] Critério de saída: roteiro semanal personalizado + próximos passos pós-Kit
