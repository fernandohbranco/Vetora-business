---

## O que é este diretório

O conteúdo bruto dos 8 módulos do Kit VETORA Completo (R$397). Cada módulo é um arquivo independente, construído com a profundidade do **Branding Book de referência** — das camadas internas (fundação) às externas (percepção).

Não é um pack de templates: é o método de uma consultoria de branding empacotado para aplicação solo, com critérios objetivos de saída em cada módulo.

---

## Princípio de profundidade — espelho do Branding Book

Cada módulo do Kit desenvolve, em profundidade, uma camada que o **Diagnóstico de Autoridade** (produto de entrada) apenas mede. A correspondência é direta:

| Camada do diagnóstico | Módulo do Kit | Bloco do Branding Book de referência |
|---|---|---|
| Fundação Estratégica | 01 — Diagnóstico de Marca | Bloco 1 (Fundação) |
| Posicionamento | 02 — Posicionamento e Estratégia | Bloco 2 (Posicionamento) |
| Identidade Verbal | 03 — Identidade Verbal | Bloco 3 (Verbal) |
| Identidade Visual | 04 — Identidade Visual | Bloco 4 (Visual) |
| Presença e Aplicações | 05 — Estrutura de Site | Blocos 5–6 (Aplicações) |
| Autoridade e Percepção | 06 — Apresentação Comercial | Bloco 7 (Brand Experience) |
| (transversal) | 07 — Biblioteca de Prompts de IA | acelera todos |
| (governança) | 08 — Guia de Implementação | Bloco 8 (Gestão de Marca) |

---

## Sequência de construção (Método VETORA)

```
DIAGNÓSTICO        →  DIREÇÃO              →  CONSTRUÇÃO                  →  ENTREGA            →  EVOLUÇÃO
Módulo 01             Módulos 02 + 03         Módulos 04 + 05 + 06          (checklists)          Módulo 08
```

O Módulo 07 (Prompts) é transversal — acelera todas as etapas. O Módulo 08 fecha o ciclo e orienta o uso na ordem certa.
