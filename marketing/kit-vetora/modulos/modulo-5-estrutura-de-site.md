# Módulo 5 — Estrutura de Site

> Um site institucional não é uma brochura digital. É o vendedor que trabalha por você 24 horas por dia — e precisa comunicar valor, gerar confiança e provocar ação, nessa ordem.

---

## O que é e para que serve

Este módulo entrega a estrutura completa de um site institucional eficaz: o wireframe das seções, os blocos de copy prontos para adaptar, e o checklist UX/UI para garantir qualidade antes de publicar.

O objetivo não é criar um site genérico. É criar uma estrutura que:
- Comunica posicionamento em menos de 5 segundos (regra do scroll inicial)
- Guia o visitante da curiosidade ao contato ou compra
- Funciona bem em mobile (onde a maioria do tráfego vem)
- Transmite nível de qualidade compatível com o preço do serviço ou produto

---

Este wireframe é universal para negócios de serviços, consultoria, produtos digitais e profissionais liberais. Adapte o conteúdo de cada seção para o seu contexto.

## Checklist UX/UI (30 pontos)

Use este checklist antes de publicar qualquer site ou landing page.

### Bloco A — Clareza (10 pontos)

- [ ] Em menos de 5 segundos, fica claro o que o site oferece?
- [ ] O headline principal responde: para quem é e qual o resultado?
- [ ] O CTA principal é visível sem scroll (above the fold)?
- [ ] O texto do CTA é específico ("Quero o Kit" em vez de "Clique aqui")?
- [ ] As seções têm ordem lógica: problema → solução → prova → oferta?
- [ ] O visitante sabe o que fazer depois de ler cada seção?
- [ ] Não há texto desnecessário que distraia do CTA principal?
- [ ] O título de cada seção é claro mesmo sem ler o corpo?
- [ ] A proposta de valor aparece acima do fold?
- [ ] O preço (se aplicável) está em contexto — não solto?

### Bloco B — Visual (10 pontos)

- [ ] As cores usadas são da paleta definida (máx. 3 por seção)?
- [ ] As fontes usadas são as fontes definidas (máx. 2 famílias)?
- [ ] Há espaçamento suficiente entre elementos (não parece lotado)?
- [ ] Os ícones são lineares e consistentes?
- [ ] As imagens seguem o guia fotográfico definido?
- [ ] A logo está na versão correta para o fundo usado?
- [ ] O contraste entre texto e fundo passa no nível AA (4,5:1 mínimo)?
- [ ] Os botões têm a cor de destaque definida?
- [ ] O layout não tem mais de 3 níveis de hierarquia visual por seção?
- [ ] A página parece um sistema coerente — não um conjunto de seções independentes?

### Bloco C — Mobile (5 pontos)

- [ ] O site funciona bem em tela de 375px (iPhone SE)?
- [ ] Os textos são legíveis em mobile sem zoom?
- [ ] Os botões têm pelo menos 44px de altura (área de toque adequada)?
- [ ] Imagens não quebram o layout em mobile?
- [ ] O CTA é visível e clicável sem precisar de zoom?

### Bloco D — Técnico (5 pontos)

- [ ] O site carrega em menos de 3 segundos em conexão 4G?
- [ ] As imagens estão otimizadas (WebP, máx. 200kb por imagem)?
- [ ] O site tem meta title e meta description preenchidos?
- [ ] O Open Graph está configurado (imagem para redes sociais)?
- [ ] O site tem SSL (https:// ativo)?

1. O **wireframe** é a estrutura para codificar a landing page (Sprint 2 do Kit VETORA)
2. Os **blocos de copy** são pontos de partida — adapte com o tom de voz do Módulo 3
