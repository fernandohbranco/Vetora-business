# Identidade — {{NOME}}

Marca **do cliente**, aplicada no que o cliente **publica** (posts, site,
carrossel, página de vendas). Não confundir com a marca VETORA, que vai nos
entregáveis que a VETORA **entrega** ao cliente (essa vem do container).

Preenchido pelo `/instalar` ou pelas skills de identidade. Arquivos esperados
quando a identidade estiver definida:

- `design-guide.md` — cores, tipografia, tom visual (referência das skills visuais)
- `design-system/MASTER.md` — sistema de design (gerado pelo `/ui-ux-pro-max`)
- `logo/` — arquivos de logo
- `manifesto.md` — posicionamento e narrativa de marca

Enquanto vazio, as skills visuais avisam que a identidade ainda não foi
definida e usam um fallback neutro.
