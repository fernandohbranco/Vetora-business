# Outputs — /frontend-design

## O que essa skill produz

**Output principal:** inline — plano de design + código

### Fase 1 — Plano de design (inline)
- Token system compacto: paleta (4–6 hex nomeados), tipografia (display + body + utility), conceito de layout
- Elemento-assinatura: o único detalhe memorável da página
- Autocrítica contra o brief antes de codar

### Fase 2 — Código
- HTML/CSS/JS ou componente React/TSX conforme o projeto
- Responsivo (mobile-first), foco visível, `prefers-reduced-motion` respeitado
- Sem padrões genéricos de AI: sem cream+serif+terracotta, sem near-black+neon, sem broadsheet+hairline

## Quem chama essa skill
- `/pagina-de-vendas` — para direcionar decisões visuais antes de buildar
- `/carrossel` — como referência de princípios quando não há design-system

## O que essa skill consome
- `identidade/design-guide.md` — cores, fontes e logo já definidos
- `identidade/design-system/MASTER.md` — se existir
- `_memoria/empresa.md` — contexto do negócio para fundamentar escolhas
- Brief do usuário — sempre a fonte primária
